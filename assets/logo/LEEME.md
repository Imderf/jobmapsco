# Logo de Job Maps CO

Mapa plegado de Colombia hecho con curvas de nivel reales (relieve SRTM, el mismo del mapa), con el nombre debajo.

| Archivo | Uso |
|---|---|
| `marca.svg` / `marca.png` | Solo el mapa plegado, fondo transparente, líneas blancas. Para fondos oscuros. |
| `logo.png` | Mapa plegado con "JOB MAPS CO." y el lema, fondo transparente. |
| `logo-fondo-negro.png` | Lo mismo sobre negro, 1920x1080. |
| `avatar-1080.png` / `avatar-400.png` | Cuadrado para perfiles. |
| `portada-linkedin-1584x396.png` | Portada de LinkedIn. |

- Colores: líneas blancas, "CO." en azul `#2f6bff`, lema en gris. Fondo siempre oscuro.
- Tipografía del nombre: Inter 500 con tracking amplio; el lema en JetBrains Mono.
- Los archivos son estáticos: no se cargan desde `index.html` todavía (el favicon sigue siendo `favicon.svg`).
- Autor del logo: Jaime Orozco, 2026-10-13.
